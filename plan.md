## Design direction

**Movement:** quiet editorial modernism with restrained Sri Lankan garden/arch motifs from the existing version 8 site. **Principles:** evidence before assertion; visual calm; multilingual legibility; one clear action per screen. **Palette:** preserve warm ivory and botanical green, with a distinct deep-jade signature color for navigation and primary actions; reserve amber for careful attribution rather than urgency. **Layout:** editorial reading columns and asymmetric feature panels, with deliberate whitespace rather than dense dashboard grids. **Motifs:** the existing rosette, arch framing and small source-reference rules. **Interaction:** predictable route transitions, clear focus and status announcements, never unexpected media playback. **Animation:** subtle opacity/position transitions of roughly 150–250 ms, no animation required to understand content, reduced-motion respected. **Typography:** a readable Latin editorial serif plus a restrained sans UI face; select tested Tamil/Sinhala fallback families for correct shaping and line height. **Brand essence:** source-aware Islamic learning for a thoughtful multilingual community; calm, honest, welcoming. **Voice:** plain, humble, specific—“Explore the source behind this reading” and “No confirmed gatherings have been posted yet.” **Wordmark:** retain/refine the supplied rosette + distinct Dragon Dawwa lettering rather than a default text logo.
