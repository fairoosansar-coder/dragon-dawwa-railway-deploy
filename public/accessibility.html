ACCESSIBILITY

Calm, direct controls that do not depend on motion.

This interface includes practical accessibility support, but it does not claim formal conformance certification or perfect support in every browser or assistive technology.

Keyboard first.
Controls state what they do.

Keyboard and focus

Pages include a Skip to content link, semantic labels for form fields, visible focus styling, ordinary links and buttons, and live status regions for loading, error and completion messages. Mobile navigation is a real button with an expanded state.

Language and script

The interface selector offers English, Tamil and Sinhala navigation and study controls. Qur’an Arabic is marked with Arabic language and right-to-left direction; it is not replaced by an automatic interface-language translation. Tamil and Sinhala fallback font families are included in the visitor styles.

Motion, reading and audio

Reduced-motion preferences remove nonessential animation and smooth scrolling. Study narration does not autoplay. It uses native audio controls for seeking, alongside Play, Pause, Replay and speed controls. The microphone action appears only when the browser offers the required APIs.

Helpful ways to use the site

Use Tab and Shift+Tab to move through links and controls; Enter or Space activates buttons. On a narrow screen, use the menu button to reveal navigation. Reader and study status messages are exposed with live regions. If an external source, browser audio function or microphone permission is unavailable, use the text and source-link alternatives.

Known boundaries

Native audio controls, external source sites and browser permission prompts are controlled by the visitor’s browser or the external service. The current interface has responsive rules for narrow widths and reduced motion, but device- and assistive-technology-specific testing should be recorded separately rather than inferred from these controls.
