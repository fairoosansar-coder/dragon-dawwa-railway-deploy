# Starter resources — source and rights record

**Checked 5 October 2026.** The browseable catalogue is `public/data/starter-resources.json`. It contains **12 distinct direct links** across six learning themes. These are external resources **curated for navigation only**; they are not Dragon Dawwa-authored teachings, endorsements, claimed authenticity grades or permission to redistribute publisher text. Catalogue descriptions are newly written summaries. Only original-publisher links are displayed; no complete article, PDF, translation, recitation or course is copied or embedded. Displayed source languages are the ones observed, not assurances every translation or feature is available in every listed language. Human religious/language review is still required for locally authored instruction.
