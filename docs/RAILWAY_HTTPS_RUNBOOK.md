## Original operating envelope and the formerly $20 compute cap

[Railway Pro pricing](https://docs.railway.com/pricing/plans) is a **$20/month subscription with the first $20 of metered usage included**, not $20 + $20 free. RAM is $10/GiB-month, CPU $20/vCPU-month, volume $0.15/GB-month and egress $0.05/GB. The [compute hard limit](https://docs.railway.com/pricing/cost-control) includes CPU, memory, storage and egress **across this workspace** and takes all services offline at its threshold; it is a kill switch, not a service guarantee or fixed all-inclusive quote.
